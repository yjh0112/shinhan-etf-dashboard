[ 사전 준비 — 1회만 ]
  1. Git 설치   → https://git-scm.com
  2. Node 설치  → https://nodejs.org  (LTS 버튼)
  3. GitHub 저장소 생성
     → https://github.com/new
     → 이름: shinhan-etf-dashboard
     → Public 선택 후 Create

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[ STEP 1 ] ZIP 압축 풀기
  → etf-dashboard 폴더 생성됨
  → 그 폴더 안에서 터미널 열기
    (Windows: Shift+우클릭 → PowerShell 열기)
    (Mac:     우클릭 → 폴더에서 새 터미널 열기)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[ STEP 2 ] 터미널에 아래 6줄 순서대로 복붙

git init
git add .
git commit -m "첫 커밋"
git branch -M main
git remote add origin https://github.com/yjh0112/shinhan-etf-dashboard.git
git push -u origin main

  ※ GitHub 로그인 팝업 뜨면 로그인하면 됩니다

[ STEP 3 ] GitHub Pages 켜기
  1. https://github.com/yjh0112/shinhan-etf-dashboard
  2. Settings 탭 → Pages (왼쪽 메뉴)
  3. Source: Deploy from a branch
  4. Branch: gh-pages 선택 → Save
  5. 1~2분 기다리면 완료!
